Apple Exam Runner

Connect a tab, navigate to any supported exam in that tab, then fill it automatically.

Each session opens its own browser window with its own profile, so you can log a different Apple account into each one and run them at the same time. Open this page in another browser tab, pick another session there, and the two runs stay completely apart.

Walks every tab, program and section this account can reach, opens each resource and quiz in its own tab, and keeps going past anything it cannot pass — that lands in the report as a failed exam. A quiz that fails is retried later in the same run with whatever the grading has since confirmed, so a brand-new account climbs on its own.
